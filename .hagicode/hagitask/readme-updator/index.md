# README requirements

## Audience and focus

- Address people who use Hagihub, the Electron desktop app for working with several GitHub accounts, and developers who build it. The README is written in Chinese; keep it in Chinese.
- Open with the positioning statement and the list of what the current version supports.

## Required content

- Keep the tech stack, usage, project structure, development, build, CI/CD and license sections.
- State only login and repository features that `src/` shows; keep the statement that the access token stays in the Electron main process.
- Keep the Apache-2.0 license badge consistent with `LICENSE`.

## Exclusions

- Exclude OAuth client secrets, access tokens, signing credentials, internal hosts, machine-specific paths and private links.
